# 2026-11-14

## 打包规则改造（ArcaneChat fork → AwkMail）

用户约束：**本地无构建环境，只靠 GitHub Actions 打包，禁止在本地执行任何构建/测试**。

最终约定：
- 应用名 / APK 文件名前缀：`AwkMail`
- applicationId：`com.example.maila`（debug 为 `com.example.maila.beta`）
- 只打包 `arm64-v8a`，APK 名 `AwkMail-arm64-v8a-<versionName>.apk`
- Release 只出 foss 渠道，不再打 gplay / universal 包

改动文件：`build.gradle`、`.github/workflows/release.yml`、`preview-apk.yml`、
`google-services.json`、`jni/Application.mk`、`makefile`、
`src/main/res/values{,-zh-rCN,-zh-rTW}/strings.xml`。

## 需要记住的项目特点 / 坑

1. `build.gradle` 顶部新增 `APP_NAME` / `TARGET_ABI` 两个 ext 常量，改这两行即可换名字和架构。
   `-PABI_FILTER=xxx` 仍可覆盖 TARGET_ABI —— **必须保留**，因为
   `instrumented-tests.yml` 用 `-PABI_FILTER=x86_64` 在 x86_64 模拟器上跑测试，
   `cache-core.yml` 也仍缓存 x86_64 core（属于测试链路，不是发布产物，故意保留）。
2. `scripts/rebrand.sh` 在 CI 构建时（`ndk-make.sh` 末尾调用）会把所有 `strings.xml`
   里的 `Delta Chat` 就地替换成 `ArcaneChat`。用户明确要求 **只改英语（默认 values）+ 简中 + 繁中**
   三个 `app_name`，其余语言文件保持原样；因此非中英文系统语言下桌面图标名仍是 `ArcaneChat`。
   `undo_rebrand.sh` 同理不影响 `AwkMail`。
3. `com.google.gms.google-services` 插件按 applicationId 匹配 `google-services.json` 里的 client，
   包名不匹配会直接构建失败。已把原 `chat.delta.lite` / `.beta` 两个 client 的包名改为新值；
   该文件仍是上游 Firebase 项目，gplay/FCM 对新包名不会真正可用（foss 不使用 FCM，不影响发布包）。
4. 应用内仍有 ArcaneChat 硬编码品牌文案与链接（通知标题、崩溃报告、欢迎语、帮助页、
   `AppUpdate.java` 的 CLIENT_ID=`arcanechat`）、README / fastlane 文案，本次按范围未改。
5. `code-format.yml` 会跑 `spotlessCheck`（greclipse 格式化 `*.gradle`），改 build.gradle
   时需保持与原文件相近的 Groovy 风格；`values*/strings*.xml` 被 spotless 排除，不受影响。
